## 📌 Project Highlights

### 📊 EDA Project — Zameen.com Real Estate Analysis
- Cleaned and explored **Zameen.com** property listings dataset
- Generated visual insights on pricing trends, property types, and location analysis
- Delivered a comprehensive EDA report

### 🤖 ML Assignment — PSL Cricket Predictions
- Built machine learning models on PSL innings and match datasets
- Applied data preprocessing, feature engineering, and model evaluation
- Documented findings in a detailed report

### 🏥 SQL Portfolio Project — Hospital Management System
- Designed a relational database schema for hospital management
- Wrote complex SQL queries for data retrieval and reporting
- Created a Power BI dashboard for visual analytics

### 📈 Power BI Portfolio Project — Amazon Sales Dashboard
- Analyzed Amazon clothing sales data for 2025
- Built an interactive Power BI dashboard with filters and KPIs

### 🧹 Web Scraping Assignment
- Developed a Python script to scrape and extract structured data from websites

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Faizi-2k28/AtomCamp_Projects.git
   ```

2. **Explore the projects** — each folder contains the assignment brief, datasets, and completed work.

3. **For Python/Jupyter projects**, install dependencies:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```

4. **For Power BI projects**, open `.pbix` files in [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
